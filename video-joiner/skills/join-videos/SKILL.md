**ตอบผู้ใช้เป็นภาษาไทยเสมอ** ใช้คำง่าย ๆ ผู้ใช้อ่านภาษาอังกฤษไม่ถนัด
ถ้าคำสั่งแสดงข้อความภาษาอังกฤษ (เช่น error จาก ffmpeg) ให้แปลและอธิบายเป็นภาษาไทย

รันจากรากของปลั๊กอิน: `cd "${CLAUDE_PLUGIN_ROOT}"` (ต้องมี `ffmpeg` 5.1 ขึ้นไป และ Python 3.9 ขึ้นไป)

## ขั้นแรกทุกครั้ง: ตรวจและติดตั้งโปรแกรมที่ต้องใช้ให้อัตโนมัติ
ผู้ใช้ไม่ถนัดพิมพ์คำสั่งเอง ให้ทำแทนทั้งหมด:
1. บอกผู้ใช้สั้น ๆ เป็นภาษาไทยว่า "จะตรวจว่าเครื่องมี ffmpeg และ Python ไหม ถ้าไม่มีจะติดตั้งให้ ขอให้กดอนุญาตเมื่อมีหน้าต่างถาม"
2. รันสคริปต์ตามระบบ:
   - Windows: `powershell -NoProfile -ExecutionPolicy Bypass -File "${CLAUDE_PLUGIN_ROOT}/scripts/setup.ps1"`
   - macOS / Linux: `bash "${CLAUDE_PLUGIN_ROOT}/scripts/setup.sh"`
3. อ่านผล:
   - "พร้อมใช้งาน" → ไปต่อ ใช้คำสั่ง Python ตามที่สคริปต์บอก (`python3`, `python` หรือ `py`) แทน `python3` ในคำสั่งข้างล่าง
   - exit 3 (ติดตั้งแล้วแต่ยังหาไม่เจอ) → บอกผู้ใช้ให้ปิดแล้วเปิด Claude Code ใหม่ แล้วสั่งต่อวิดีโออีกครั้ง
   - exit 1 หรือ 2 → แปลข้อความเป็นภาษาไทยง่าย ๆ และบอกว่าผู้ใช้ต้องทำอะไรทีละขั้น
ห้ามติดตั้งอะไรนอกจาก ffmpeg และ Python และห้ามข้ามการขออนุญาตของ Claude Code

## ถามช่องก่อนต่อทุกครั้ง
ผู้ใช้มี 4 ช่อง TikTok ให้ถามเป็นภาษาไทยว่า "คลิปนี้สำหรับช่องไหน" แล้วให้เลือกเลข:
1 = เสือ2992 (@www.dada198), 2 = เสือ954 (@ok_d198), 3 = ชีวิตติดรีวิวของดี (@198da_d), 4 = เจ้าเสือ (@www.wayu1989)
ใช้ชื่อช่อง (ไม่มี @) เป็นชื่อโฟลเดอร์และชื่อไฟล์
บันทึกไฟล์ที่ต่อแล้วไว้ในโฟลเดอร์ย่อยชื่อช่อง ภายในโฟลเดอร์ที่มีคลิป
ตั้งชื่อไฟล์ `<ชื่อช่อง>_<ปปปป-ดด-วว_ชชนน>.mp4` เช่น `เจ้าเสือ_2026-11-25_1900.mp4` (ไม่ทับไฟล์เก่า)
ค่าเริ่มต้นเป็นแนวตั้ง `--size 1080x1920` สำหรับ TikTok เว้นแต่ผู้ใช้ขอแบบอื่น

## ต่อคลิป
`python3 -m videojoiner a.mp4 b.mp4 -o joined.mp4`

ตัวเลือก:
- `--crossfade 0.5` เฟดซ้อนระหว่างคลิป (คลิปต้องยาวอย่างน้อย 2 เท่าของเวลานี้)
- `--music bg.mp3 --music-volume 0.25` เพลงพื้นหลัง วนซ้ำถ้าสั้น
- `--voiceover voice.wav` เสียงพากย์ เล่นครั้งเดียว (ใช้พร้อม `--music` ไม่ได้)
- `--size 1080x1920` (แนวตั้งสำหรับ TikTok) `--fps 30` `--mute`

ใช้ path แบบเต็มสำหรับไฟล์ของผู้ใช้ เพราะคำสั่งรันจากรากของปลั๊กอิน
ถ้าไฟล์ผลลัพธ์ไม่มีเสียง เครื่องมือจะแจ้ง error ให้รายงานผู้ใช้ตรง ๆ อย่าซ่อน

## Gemini (ไม่บังคับ)
ต้องมี `GEMINI_API_KEY` จาก Google AI Studio ใน environment
ห้ามขอให้ผู้ใช้วาง key ในแชท และห้ามพิมพ์ key ออกมา

- ซับไตเติล: `python3 -m videojoiner.gemini subs joined.mp4 -o subs.srt --lang th`
- เสียงพากย์: `python3 -m videojoiner.gemini speak script.txt -o voice.wav`

ชื่อโมเดลตั้งได้ที่ `GEMINI_STT_MODEL`, `GEMINI_TTS_MODEL`, `GEMINI_VOICE` ค่าเริ่มต้นยังไม่ได้ยืนยัน
ส่วนนี้ทดสอบกับคำตอบจำลองเท่านั้น ถ้าล้มเหลวให้บอกผู้ใช้ตรง ๆ

## หน้าเว็บ
`python3 -m videojoiner.web` เปิด http://localhost:8000 (ลากสลับลำดับ, crossfade, เพลง, แถบความคืบหน้า)
ใช้บนเครื่องตัวเองเท่านั้น ไม่มีระบบล็อกอิน
