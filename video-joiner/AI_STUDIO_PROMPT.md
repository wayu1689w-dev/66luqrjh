# พรอมต์สำหรับวางใน Google AI Studio (โหมด Build)

สร้างเว็บแอปต่อวิดีโอ ภาษาไทย มีฟีเจอร์ดังนี้:
1. เลือกหลายคลิป ลากสลับลำดับได้ ลบคลิปได้
2. ปุ่ม "สร้างซับไตเติลอัตโนมัติ": ส่งเสียงของวิดีโอให้ Gemini ถอดเสียงเป็นภาษาไทย
   ได้ผลเป็น JSON [{start, end, text}] (วินาที) แล้วแสดงให้แก้ไขได้ และดาวน์โหลดเป็น .srt
3. ปุ่ม "สร้างเสียงพากย์": ผู้ใช้พิมพ์สคริปต์ เลือกเสียง ให้ Gemini TTS สร้างเสียง
   (ผลเป็น PCM 16-bit mono 24kHz ต้องแปลงเป็น WAV ก่อนเล่น) และกดฟังตัวอย่างได้
4. ห้ามฝัง API key ในโค้ดฝั่งเบราว์เซอร์ที่เผยแพร่ ใช้ key ผ่านระบบของ AI Studio เท่านั้น

หมายเหตุ: การต่อไฟล์วิดีโอจริง (ซิงก์เสียง, crossfade, ผสมเพลง) ให้ใช้โปรเจกต์
`video-joiner` ใน repo นี้ที่ใช้ ffmpeg เพราะเบราว์เซอร์ล้วนทำได้ไม่ดีพอ
